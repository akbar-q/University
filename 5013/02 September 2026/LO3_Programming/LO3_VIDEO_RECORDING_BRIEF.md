# LO3 Individual Professional Discussion Video Recording

## Purpose

Record an individual 5-7 minute technical explanation of your Smart Environmental Monitoring System implementation. This is LO3 evidence alongside your code, simulation/hardware screenshots and test records. It is not a group presentation: each student must explain their own understanding and contribution.

## What to Show

1. **System overview:** show a block diagram and state the LDR, switch, LED, buzzer and LCD functions.
2. **Code walkthrough:** explain one complete path from input reading to the decision and output action. Use your own source code.
3. **Test evidence:** show your initial and refined test plans plus at least one completed result.
4. **Debugging:** explain one real issue, the evidence used to find it, the fix and retest result.
5. **Evaluation:** state one limitation and a justified improvement. Refer to peer feedback where available.

## Suggested Timing

| Time | Content |
| ---: | --- |
| 0:00-0:45 | Purpose, requirements and block diagram |
| 0:45-2:30 | Code walkthrough |
| 2:30-3:45 | Testing evidence |
| 3:45-5:00 | Debugging example |
| 5:00-7:00 | Evaluation, peer feedback and improvement |

## Submission Files

- Video file or approved recording link.
- Final commented code.
- Simulator/hardware screenshots and serial log where used.
- Initial and refined test plans with results.
- Issues-and-fixes table.

## Evidence Checklist

- Your face or voice is identifiable throughout the explanation.
- You explain the code in your own words and can connect each named pin to the circuit.
- Your video includes evidence rather than unsupported claims.
- Your evaluation identifies a realistic limitation, trade-off or failure mode.
- Files are named with your student ID and submitted by the published deadline.

## LO3 Mapping

| Criterion | Video evidence |
| --- | --- |
| LO3.P4 | Explain readable code that implements the design |
| LO3.P5 | Show an initial test plan covering a subset of functions |
| LO3.M4 | Show a refined test plan covering normal, edge and fault cases |
| LO3.D3 | Evaluate a working system with peer feedback, test evidence and justified improvements |
