## Platform Choice

Tinkercad with Arduino Uno is the primary simulator for Weeks 1-3 because it supports the beginner code and wiring patterns used in the retained student work. Wokwi is introduced for the I2C LCD, advanced simulation and ESP32 extension work. The LO1 report still requires a justified comparison of Arduino-class, ESP32 and STM32 platforms.
