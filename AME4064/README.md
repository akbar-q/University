# AME4064 - Year 1 Introduction to Mechatronics

This pack provides the Year 1 bridge into the annual Design Challenge. It teaches only the essential electrical, electronic, motor-drive and microcontroller foundations needed by mechanical engineering students, then applies them to a small safe prototype.
