# Unit 5041 — Weekly Teaching Slide Outlines (8 weeks)

These markdown files are **slide-by-slide teaching outlines** for an 8-week delivery where students complete **individual projects**.

Students can choose either pathway:
- **MATLAB simulation/model-based project**
- **Hardware project (embedded/mechatronics)**

The teaching sequence is the same for both pathways:
LO1 (proposal) → LO2 (Jira plan + KPIs) → LO3 (execute/test/report/evaluate) → LO4 (presentation + feedback + reflection/PD).

Files:
- `Week1_PPT_Outline.md` … `Week8_PPT_Outline.md`

How to use:
- Treat each “Slide” as a prompt for what must be on screen plus what to say.
- Keep examples flexible: if you show a hardware example, also state the MATLAB equivalent (and vice versa).
# Unit 5041 — Presentations

This folder contains **slide-by-slide presentation outlines** for each weekly 4-hour session.

Format used:
- Each file is a Markdown slide outline.
- Each slide includes:
  - **Slide title** and **on-slide bullets**
  - **Speaker notes** (what to say, timing, prompts)
  - **In-class activity instructions**
  - **Resources** (docs to point students to)

Recommended workflow:
- Convert these outlines into PowerPoint (or present directly from Markdown).
- Keep the *same* slide numbering when you customize so it stays aligned to lesson plans and deliverables.
