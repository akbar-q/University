# LO3 — Technical Report & Evidence (P4–P6, M3–M5, D3)

## What to submit for LO3 (recommended)
- Individual document:
  - `S3_LO3_TechnicalEngineeringReport_<StudentID>.pdf` (or `.docx`) created from `TEMPLATE_S3_LO3_TechnicalReport_Combined.md`
- Evidence index:
  - include Appendix A in the report using `TEMPLATE_S3_LO3_EvidenceIndex.md` (or submit as a separate PDF if your centre prefers)
- Individual document (one per student):
  - `S3_LO3_Logbook_<StudentID>.pdf` (or `.docx`) created from `TEMPLATE_S3_LO3_IndividualLogbook.md`

## Evidence rule
If a claim matters, it must point to evidence:
- a test result
- a log file
- a photo/video
- a Jira change/decision
