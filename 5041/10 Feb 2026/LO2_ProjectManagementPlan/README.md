# LO2 — Project Management Plan (P3, M2, D2)

This folder contains the **templates** for LO2.

## What to submit for LO2 (recommended)
- Team document:
  - `S2_LO2_ProjectManagementPlan.pdf` (or `.docx`) created from `TEMPLATE_S2_LO2_ProjectManagementPlan.md`
- Team evidence pack (exported from Jira):
  - `S2_LO2_Jira_Exports/` (screenshots/exports of backlog, dependencies, timeline, dashboards, risk/change/decision logs)
- Individual evidence (one per student):
  - `S2_LO2_IndividualJiraEvidence_<StudentID>.pdf` (or `.docx`) created from `TEMPLATE_S2_LO2_IndividualJiraEvidence.md`

## Notes
- LO2 is where you prove you can use **project management software/tools/techniques** (Jira) to plan, monitor and control the project.
- Evidence matters: if it isn’t in Jira exports or screenshots, it didn’t happen.
