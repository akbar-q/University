# LO1 — Proposal Pack (P1, P2, M1, D1)

This folder contains **templates and guidance** for the LO1 submission for Unit 5041.

LO1 goal (plain language):
- Define a clear engineering project (the ESP32 coffee-machine controller) with **aims/objectives**, **feasibility justification**, and a **responsible proposal** considering regulation/ethics/risk.

## What to produce for LO1
### Required deliverables (what gets submitted)
- Team document (preferred: single file):
	- `S1_LO1_ProposalPack` (export to `.pdf` or `.docx`) using `TEMPLATE_S1_LO1_ProposalPack_Combined.md`
- Individual document (one per student):
	- `S1_LO1_IndividualContribution_<StudentID>` (export to `.pdf` or `.docx`) using `TEMPLATE_S1_LO1_IndividualContribution.md`

## How to use (recommended)
1) Fill the combined proposal pack template (team).
2) Export as a single `.pdf` or `.docx` for submission.
3) Each student completes the individual contribution statement.

## Evidence rule
Every major claim should have at least one:
- citation (datasheet/standard/article), OR
- measurement (log/time/result), OR
- justified engineering assumption.
