# LO4 — Presentation + Professional Discussion (PD)

This folder contains LO4 templates and examiner resources.

## LO4 submissions (as per deliverables map)
- Individual (S4): Presentation slides + feedback record.
- Individual (S5): Professional Discussion prep notes + reflection/action plan.

## Templates/resources in this folder
- `TEMPLATE_S4_LO4_Presentation_PPT_Outline.md` (slide-by-slide template)
- `TEMPLATE_S5_LO4_PD_SampleQnA_WithCriticalAnswers.md` (sample answers at Pass/Merit/Distinction quality)
- `LO4_PD_QuestionBank_10-15min_ExaminerSheet.md` (question bank + timing plan, mapped to P/M/D coverage)

## Important note about “PPT template”
This is provided as a **PowerPoint-ready outline** (titles, bullets, speaker notes, required evidence prompts). You can paste it into PowerPoint/Google Slides and format.
