# Unit 4015 — Presentations (Two Tutors, 8 Weeks)

This folder contains **slide-by-slide presentation outlines** for each weekly session.

Delivery model:
- **Two classes per week**
- **Each class is 4 hours**
- Teaching is split by LO ownership:
  - **Miss Anu:** LO1 + LO4 (theory + safety)
  - **Mr Akbar:** LO2 + LO3 (implementation, PLC/SCADA, robotics programming)

Cohort environment assumed:
- **OpenPLC Editor + Runtime**
- **Controlino Mega PLC** hardware
- **Node-RED Dashboard (SCADA/HMI)**
- **USB serial** PLC ↔ Node-RED comms
- **Pick-and-place robot arm** access

Format used (matches your Unit 5041 outlines):
- Each file is a Markdown slide outline.
- Each slide includes:
  - **On-slide** bullets (what should be visible)
  - **Speaker notes** (what to say/do, timing cues)
  - **Activities** and **evidence capture** prompts

Folders:
- `Miss_Anu_LO1_LO4/` — Week 1–8 slide outlines for LO1 + LO4
- `Mr_Akbar_LO2_LO3/` — Week 1–8 slide outlines for LO2 + LO3

Recommended workflow:
- Convert these outlines into PowerPoint, or present from Markdown.
- Keep slide numbering stable so it stays aligned to the teaching plan and assessment evidence.
