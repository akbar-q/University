# Laboratory Equipment Risk Assessment Register

This document provides a consolidated laboratory equipment risk assessment register for the Machines Lab, Electronics Lab, and Manufacturing Lab. It is written in a tabular format aligned with the structure requested: **SL.NO**, **Equipment name**, **ID**, **Activity/Hazard Source**, **Potential Risks / Hazards**, **Risk Level**, **Control Measures / Mitigation**, and **Residual Risk**. It should be read alongside the detailed SOPs and the UAE-specific reference note where applicable.
