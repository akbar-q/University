# Manufacturing Lab Process-Based Risk Assessment Register

This document provides a process-based Manufacturing Lab risk assessment register using the format: **SL.NO**, **Process / Practical Title**, **ID**, **Activity/Hazard Source**, **Potential Risks / Hazards**, **Risk Level**, **Control Measures / Mitigation**, and **Residual Risk**.
