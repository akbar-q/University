# LO2 Maths Workbook — Example Solutions (Read First)

This folder contains worked examples for **Learning Outcome 2 (AC fundamentals)**.

## What’s inside
- `Example Q1.md` … `Example Q8.md`: step-by-step solution write-ups with comments.
- `Images/`: figures referenced by some questions (embedded using relative links so they render on GitHub).

## How to read the maths
These files use GitHub-flavoured math:
- Inline: `$...$`
- Display: `$$...$$`

If you preview in an editor that doesn’t support MathJax/KaTeX, formulas may appear as plain text.

## Notes / conventions
- Unless stated otherwise, voltages and currents are treated as **r.m.s.** values.
- Phase conventions:
  - Inductive circuits: current **lags** voltage.
  - Capacitive circuits: current **leads** voltage.

## Image files (GitHub)
If a solution file references an image like `./Images/Example%20Q6.png`, ensure the image is committed to:
- `LO2 Maths Workbook Example Solutions/Images/Example Q6.png`

## Data corrections
If a question statement contains a likely typo (e.g., an unrealistic component value), the solution will note the assumption used (for example, using $50\,\mu\mathrm{F}$ instead of $50\,\mathrm{F}$).
