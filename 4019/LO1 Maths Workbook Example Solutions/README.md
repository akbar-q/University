# LO1 Test — Important Note (Read First)

This folder contains:
- The **question paper**: `LO1 Test for Unit 4019.docx.md`
- A set of **example solution write-ups**: `Example Q1.md` … `Example Q8.md`

## Important
- The **question paper is what you must answer/submit**.
- The **example solutions do not exactly match** the question paper values.
  - The **numerical values have been changed**.
  - However, the **circuit structures/diagrams and the method of solution are the same**.

## How to use the example solutions
- Use `Example Q*.md` as a **guide/hint** for the *process* (e.g., KCL/KVL, superposition, Thevenin/Norton, maximum power transfer).
- Do **not** copy the final numbers from the examples into your test answers.
- Apply the same steps to the **numbers in the question paper**.

If anything in the diagram orientation/polarity looks different in the test paper, keep the method the same but be careful with signs and current directions.
