# Software Tutorials

This folder contains tutorial videos.

## How to use

1. Open the relevant tutorial subfolder.
2. Download the video file(s) to your device.
3. Open and watch the video(s) using your preferred media player.

## Download from GitHub

### Option 1: Download a single video file

1. Open this repository on GitHub.
2. Browse to the video file in the correct tutorial folder.
3. Click the video file name.
4. On the file page, click the download button (or open the raw file and save it).

### Option 2: Download all tutorials at once

1. Open the repository main page on GitHub.
2. Click **Code**.
3. Click **Download ZIP**.
4. Extract the ZIP on your computer.
5. Open the `Software Tutorials` folder and then the required tutorial folder.
6. Play the video files using your preferred media player.

### Optional: Clone with Git

If you use Git, run:

```bash
git clone <repository-url>
```

Then open the `Software Tutorials` folder locally.

> Note: Some platforms may not play embedded videos directly in Markdown, so downloading the video is the most reliable option.
