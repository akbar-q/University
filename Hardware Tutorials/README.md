# Hardware Tutorials

This folder contains presenter-ready tutorials and practical demonstrations for laboratory equipment.

## Tutorials

- [Scientech 801 oscilloscope tutorial](Oscilloscope/Scientech/Scientech_801_Oscilloscope_Tutorial_Script.md) - chaptered 60-minute script covering the front panel, signal-generator demonstrations, graticule measurements, and oscilloscope safety. The supplied Scientech manual is in the same folder.
- **Multimeter theory episode:** [UNI-T_Multimeter_Theory_Deep_Dive.pptx](Multimeters/Theory/UNI-T_Multimeter_Theory_Deep_Dive.pptx) - decorated 28-slide theory deck with presenter notes, covering measurement principles, ranges, resolution and accuracy, input loading, RMS/crest factor/bandwidth, model differences, safety ratings, and current-measurement theory in the final slides. Rebuild with [build_multimeter_theory_deck.js](Multimeters/Theory/build_multimeter_theory_deck.js).
- **Multimeter practical episode:** [UNI-T_UT89XD_UT171A_Practical_Video_Script.md](Multimeters/Practical/UNI-T_UT89XD_UT171A_Practical_Video_Script.md) - separate presenter script for meter controls and demonstrations: batteries, supervised/enclosed AC voltage, resistors, continuity, capacitors, diodes, LEDs, hFE, frequency/duty, NCV/LoZ/VFC, and current as the final chapter.
- **Combined source draft:** [UNI-T_UT89XD_UT171A_Multimeter_Tutorial_Script.md](Multimeters/UNI-T_UT89XD_UT171A_Multimeter_Tutorial_Script.md) - earlier combined theory/practical planning draft retained as reference; use the two split episode files above for production.

Use the exact instrument manual and the applicable laboratory safety procedures when recording or performing demonstrations. Model suffixes, ratings, terminal labels, and available functions can vary.
