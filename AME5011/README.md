# AME5011 - Year 2 Mechatronic Design Challenge

This pack supports Year 2 teams in designing, building, testing and presenting a self-contained competition vehicle. It currently applies the 2026 External Pipe Climber specification, while preserving an annual-brief adaptation process for future challenges.
