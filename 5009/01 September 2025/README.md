# 01 September 2025 - Initial Learning Period

## Overview

This folder contains materials and notes from the initial learning period for Unit 5009 - Further Programmable Logic Controllers (PLCs). The teaching for this period was split between two instructors with complementary expertise:

- **Miss Anu** - Theory and fundamental concepts
- **Mr Akbar** - Simulation software and practical implementation

---

## Teaching Structure

### Theory Component (Miss Anu)

Miss Anu focused on the theoretical foundations of PLC systems, covering:

#### PLC Selection and Industrial Applications
- Key characteristics of industrial applications
- PLC operational features and specifications
- Manufacturer comparisons and selection criteria
- Datasheet interpretation and analysis
- System requirements analysis
- Safety and regulatory standards
- Integration and expansion considerations

#### Communication and Signal Processing
- Communication links and standards in PLC systems
- Networked bus PLC systems and protocols
- Digital signal processing concepts
- Input/output signal types and characteristics
- Signal conditioning and filtering
- Noise mitigation strategies
- Wiring standards and best practices

#### SCADA and HMI Integration
- SCADA system architecture and principles
- Human Machine Interface (HMI) design concepts
- Integration of PLCs with HMIs and SCADA
- Industrial communication protocols
- Data acquisition and monitoring
- Convergence of control systems
- Industry trends and applications

#### Alternative Control Devices
- Programmable Logic Devices (PLDs)
- Peripheral Interface Controllers (PICs)
- Microcontrollers (e.g., Nordic nRF52)
- Industrial computers
- Relay logic systems
- Comparative analysis of control strategies
- Application suitability assessment

#### Interface Methods
- Relays and solid state relays
- Opto couplers and opto isolators
- Motor driver interface integrated circuits
- Sensor and actuator interfacing
- Signal isolation techniques
- Voltage and current compatibility

- Relay output control

#### Advanced Programming Features

- Complex sequencing operations
- Error handling and recovery

## Pharmaceutical Packaging Application Context

Throughout this learning period, the context of **MedPack Solutions Ltd.** pharmaceutical packaging line was used as a practical example:

### System Requirements
- Operator control interface (start, reset, emergency stop)
- Pill sensor with counting capability
- Relay-triggered actuator for packaging
- Buzzer for alerts (errors, completion)
- Emergency stop with safety interlocks
- Reset functionality

### Control Objectives
- Automated pill counting
- Precise packaging sequence
- Error detection and handling
- Safety compliance
- Process monitoring
- Fault diagnosis
