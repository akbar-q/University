# Deliverables (Unit 5009) – What Students Must Submit

This document lists the required submissions for each Learning Outcome.

---

## LO1 – Report Submission (Task 1)

**Submission type:** Report document

**You must submit:**
- LO1 report document covering Task 1 (PLC Selection and Justification – Technical Report)
- Supporting evidence included in the report (or attached as appendices):
  - Process description (automation cycle)
  - Functional requirements (DI/DO, relay outputs, voltage/current compatibility, panel mounting, expansion)
  - Comparison of at least three PLC models/manufacturers
  - Final selection justification with datasheet evidence
  - Summary IO table and system block diagram
  - Integration and expansion discussion
  - Critical reflection (trade-offs + standards/safety considerations)

**Recommended file format:** `.odt` (preferred) or `.pdf`

**Recommended supporting files (optional but strong evidence):**
- Datasheet extracts / supplier quotes as appendices
- Any diagrams as images embedded in the report

**Marking guide:**
- See [LO1 Report/MARKING-SCHEME-LO1.md](LO1%20Report/MARKING-SCHEME-LO1.md)

## LO2 – Report Submission (Task 2)

**Submission type:** Report document

**You must submit:**
- LO2 report document covering Task 2 (PLC Signal Processing and Communication)
- Evidence included in the report:
  - Wiring diagram(s) with input/output connections
  - IO allocation table
  - Operation cycle explanation
  - Error simulation results
  - Troubleshooting procedures and findings
  - Lab record documentation (dated log of build/test)
  - Discussion of signal integrity/noise and mitigation strategies
  - Communication links and standards discussion
  - Networked bus PLC systems advantages review
  - HMI/SCADA integration discussion and evaluation
  - Convergence rationale (PLC/HMI/SCADA)

**Recommended file format:** `.odt` (preferred) or `.pdf`

**Required media evidence (must be referenced in the report):**
- Recorded demonstration clip(s) OR a single full recording (students must reference timestamps in the report)

**Marking guide:**
- See [LO2 Demo/MARKING-SCHEME-LO2.md](LO2%20Demo/MARKING-SCHEME-LO2.md)

## LO3 – Video + Code Submission (Practical Tasks)

**Submission type:** Fully video recorded practical submission + project code

**You must submit:**

### A) Video recording (required)
One continuous recording OR clearly labelled clips that together cover:
- Each LO3 task being demonstrated
- Explanation of:
  - what the task does (working principle)
  - the order of operations
  - which inputs/outputs are used (addresses)
  - proof that it works (live monitoring / simulation)
- Clear demonstration of expected behaviour (including any alarms/faults where specified)

**Minimum video structure (recommended):**
- Show the wiring/IO mapping (or simulated IO mapping)
- Show ladder logic overview for the task
- Run the task and show outputs changing
- Brief explanation of why it behaves that way

### B) Code / project files (required)
- OpenPLC project folders (zipped) for the LO3 tasks
- Any supporting configuration files used by the project

### C) Task specification compliance
- All LO3 tasks must follow the strict specification and fixed I/O mapping

**Reference documents (students must follow):**
- Task list + ladder hints: [LO3/TASKS-LO3.md](LO3/TASKS-LO3.md)
- Strict task specs (order of ops + IO addresses): [LO3/TASK-SPECS-LO3.md](LO3/TASK-SPECS-LO3.md)

## LO4 – Professional Discussion (Oral Exam)

**Submission type:** Professional discussion (oral exam)

**How it will be assessed:**
- Live oral exam between the assessor and the student
- Student must answer questions and justify decisions in professional engineering terms

**You must submit (after the discussion):**
- Professional discussion notes (summary of questions/topics and key points discussed)

**Recording:**
- If required by the assessor, the discussion may be recorded (live and recorded)

**Note:** LO4 deliverable content will be finalised once the LO4 task materials are created.
